# Newmania board and toolbox correction — 2026-11-11

The imported project retained its Generic board ID, which selected the legacy simulated/Advanced toolbox. BlocklyWorkspace also hard-coded Advanced. Newmania projects without deviceConfigs had no Motor/PS4 device categories.

The Board selector has one Newmania option. For a legacy project it is disabled and a separate warning identifies the actual source board; the legacy workspace has no insertion toolbox and connecting/building is blocked. Export keeps its original board. The confirmation dialog creates a separate Newmania project, preserving all workspace blocks, variable IDs and source project data. Compatibility diagnostics list block types and IDs against the existing Newmania validator. Missing Newmania devices use the tested default configuration; the resolved React value is memoized.

The default toolbox has eight groups, 53 entries / 47 distinct block types (including the three variable entries; Blockly renders variables dynamically). Motor has ten entries, including four presets of the existing motor-spin block for M1–M4; no new block type or robot macro was added. PS4 has five entries: press/release event presets, button, joystick, connection status. It uses the existing real D1/I2C Newmania runtime, not simulation. Math/logic no longer repeat the same entries between groups. Existing block registrations and generator behavior remain available for saved workspaces; unsupported blocks are preserved and diagnosed.
